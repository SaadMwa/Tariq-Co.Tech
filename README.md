# Tariq & Co.Tech Website

Static website for **Tariq & Co.Tech**, positioned as a premium software studio building custom systems, web products, dashboards, workflow automation, and business-focused digital platforms.

## Current Experience

- Cinematic dark hero with a lightweight interactive systems-map canvas.
- GSAP-powered entrance, scroll, parallax, and button motion when CDN assets load.
- Reduced-motion and no-GSAP fallback using IntersectionObserver.
- Project data centralized in `script.js` with clear contributor attribution.
- Real project screenshots are loaded from `images/` where available.
- Veylora is shown without a live link because no verified URL exists in the current repo data.

```bash

```

Open `http://localhost:3000/`.

## Files

- `index.html` - site structure, SEO metadata, hero, sections, and CDN references
- `style.css` - visual system, responsive layouts, project showcase, and accessibility states
- `script.js` - project data, rendering, GSAP motion, canvas interaction, navigation, and contact form handling
- `server.js` - local static file server
- `images/` - logo and project screenshots
